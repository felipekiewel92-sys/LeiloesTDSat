# Projeto Leilões TDSat

Este repositório contém o projeto Java **LeilõesTDSat**, desenvolvido como atividade prática para a unidade curricular de controle de versão e desenvolvimento de software do Senac.

## 📌 Descrição do Projeto
O sistema tem como objetivo gerenciar o cadastro e a listagem de produtos para um sistema de leilões, permitindo a persistência de dados e a integração com banco de dados MySQL.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Java
* **IDE:** NetBeans
* **Banco de Dados:** MySQL
* **Controle de Versão:** Git / GitHub
